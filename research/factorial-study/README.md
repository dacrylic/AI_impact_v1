# Factorial Study Archive

This directory contains the curated decision evidence for selecting the
production AI-impact label policy. It is intentionally separate from the
runtime package.

## Contents

- `ai_impact_scoring_management_decision_deck_v8.pptx`: approved management
  decision deck.
- `ai_impact_scoring_word_for_word_presenter_script_v1.docx`: read-aloud
  presenter script.
- `FACTORIAL_COMPLETE_ANALYSIS_V2.md`: detailed matched-panel analysis.
- `COLLEAGUE_SCRIPT_REPRODUCTION.md`: evidence that the historical dashboard
  method could be strongly reproduced once the original call details were
  recovered.
- `supporting-analysis/`: additional prompt-reconstruction, sampling,
  reproducibility, and readout notes from the investigation.

## Scope

The study compares scoring guidance, LLM version and task format on a matched
task panel. It supports the approved **current POC guidance + GPT-5.2 +
normalized/decomposed task** policy. It does not claim that the new live-tool
distribution is a revised national dashboard statistic.

Raw model responses, source task data, temporary renders and local result
directories are deliberately excluded from version control. They should be
retrieved from the governed analysis workspace or artefact store when an audit
requires them.
